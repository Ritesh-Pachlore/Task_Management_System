⑥ is_active — What It Controls in Each Table

Column Table What It Soft-Deletes Use Case
is_active task_details Entire task for ALL employees "Delete Task" button (already coded in SQL, just needs UI button)
is_active task_execution_log Only ONE employee's membership in group "Remove from Group" — only that member disappears, others still see the task
⚠️ Current gap for task_details.is_active: The SQL already filters WHERE is_active = 1 in both sp_fetch_task_list and sp_dashboard_counts. Only missing: a "Delete Task" button on the Edit page that calls an API to set task_details.is_active = 0.
